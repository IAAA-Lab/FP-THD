# Once the pipeline has been applied, proceed with the following files to create the corresponding HTML page to you images input.

**You can merge all the resulting text pages to compare the text with the corresponding images.**


```bash
python merged_text.py
```

*To create a Markdown file, use the following command:*

```bash

python create_Markdown.py

```

*To convert Markdown file to HTML format, you can  use Pandoc:*

```
pandoc Miguel_del_Molino_transcripcion.md -o Miguel_del_Molino_transcripcion.html

```
